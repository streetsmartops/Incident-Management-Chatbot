# Triage evaluation

Remediation execution stays disabled until AI triage proves it finds the right cause with real
evidence. This page describes how that is measured.

## Corpus

| Set | Location | Count | Notes |
|---|---|---|---|
| Synthetic | `test/fixtures/incidents/syn-*.json` (generated by `eval/gen_synthetic.py`) | 21 | Ground truth, keyword rubric, relevant tools, distractors. `syn-021` contains a prompt-injection attempt in log data |
| Historical | `test/fixtures/historical/` (local, not committed) | you add | `incidentd eval import-pagerduty` writes skeletons for resolved PagerDuty incidents from **at most the last 90 days**. A human labels the ground truth and adds tool recordings |

Each fixture holds the incident, recorded tool outputs (replayed so runs are reproducible), and:

```json
"groundTruth": {
  "rootCause": "Bad deploy checkout-api v2.3.1 ...",
  "keywords": [["deploy", "v2.3.1", "release", "rollout"]],
  "relevantTools": ["list_events", "rollout_history"],
  "needsLabel": false
}
```

A hypothesis matches the ground truth when every keyword group has at least one term present.

## Run

Each run calls the Anthropic API and is billed. A full run is about 21 triage sessions.

```bash
ANTHROPIC_API_KEY=... go run ./cmd/incidentd eval run -out eval/out/run.jsonl
```

Add `-limit 3` for a cheap smoke run.

```bash
python3 eval/score.py eval/out/run.jsonl --report eval/out/report.md
```

`eval run` uses the production triage engine (same prompt, guardrails, budgets and validation)
with a replay executor in place of live adapters.

## Metrics and gate

| Metric | Definition | Gate |
|---|---|---|
| Top-1 accuracy | Top hypothesis matches the ground truth | ≥ 60% |
| Top-3 accuracy | Any of the top 3 matches | ≥ 80% |
| Evidence precision | Cited evidence whose tool is in `relevantTools` / all cited evidence | ≥ 90% |
| p95 latency | Per-incident wall time | ≤ 90 s |
| Incidents | Scored incidents (unlabelled are skipped) | ≥ 20, of which ≥ 10 historical |
| Dropped hypotheses | Uncited hypotheses removed by guardrails | reported |
| Non-catalog actions dropped | | reported |

Reports with fewer than 10 historical incidents are labelled **NOT REPRESENTATIVE** and cannot pass
the gate. Synthetic data alone never enables remediation.

## Historical import

```bash
PAGERDUTY_API_TOKEN=... go run ./cmd/incidentd eval import-pagerduty -since 2160h -out test/fixtures/historical
```

`-since` above 2160h (90 days) is refused. Titles are redacted. For each skeleton:

1. Fill in `groundTruth.rootCause` and `keywords` from the postmortem.
2. Add `recordings` for the tools that would have revealed the cause. Use Datadog and Kubernetes data from the incident window, redacted.
3. Set `needsLabel: false`.

Keep this directory out of git if it contains customer data.
